project idea: an interface that creates maps of concepts of a subject.

map structure:
- name of the subject (e.g.: "quantum chemistry") as a header at the top of the page
- concept box: individual concepts (e.g.: "wave-particle duality") in a large box and in large font text
- detail box: relevant examples, instances of the concepts in real life, details, or other information (e.g. "ultraviolet catastrophe") placed in smaller boxes in smaller font text; must be connected via a line to a concept box
  - the detail box by itself shows a preview or summary of the content; clicking on the detail box expands to show the full definition/detail. the preview/summary of the content will be auto-generated by Claude after the full definition/detail is inputted by the user and saved.
  - clicking on the line between a detail box and concept box produces a small modal window next to the place that was clicked, describing the relation between the detail and the concept (e.g.: "ultraviolet catastrophe suggested that light has a particle-light behavior")

user interface:
- at the very bottom of the map, there should be an icon indicating the "editability". the icon is an eye when the mode is "viewing", and the icon is a pencil when the mode is "editing".
- when the mode is "viewing", the elements of the concept map cannot be changed (can't add more boxes or lines)
  - clicking on a box centers the box in the window, pushing aside other boxes and connection lines out of the way in a natural, buoyant fashion. 
  - clicking on an empty space in the concept map returns the map to its normal state.
- when the mode is "editing":
  - the user can right-click on any blank space to add an element - show a dropdown (choose between concept box and detail box; (2) remove an element). 
  - when adding a box, create a square with one rectangular text box at the top of the square for a title and another rectangular text box for the rest of the square allowing the user to type details. the font in the title text box should be larger. 
    - the user can elect to have Claude generate a description of the topic types in the title text box, by clicking a small button below the box square that says "generate definition"
  - when the user's cursor hovers over the edge of an existing box, a small circle on the edge of the box should appear by the cursor, and allow the user to drag out a connection line with their mouse/cursor to another box (show a small circle on the edge of whatever box is being hovered over by the cursor, and remove the circle when it disappears).
  - when the user clicks on an existing element, they can press the delete/backspace key on their keyboard to delete the element, or directly modify the text in the concept/detail box, or the text accompanying the connection line.
- appearance of elements:
  - concept boxes in a light blue gradient background (periwinkle)
  - detail boxes in a slightly darker blue background
  - connection lines a light gray; not super bright or having high visual weight, but clearly visible
  - background: a dark blue-purple-gray
